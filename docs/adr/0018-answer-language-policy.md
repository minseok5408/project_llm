# ADR 0018: 현재 질문에 따른 답변 언어

상태: 구현. 2026-09-12.

## 문제와 범위

한국어로 질문했는데 `职业规划(커리어)`처럼 요청하지 않은 중국어 표현이 답변에 섞이는 사례가 있었다. 사용자는 현재 질문·입력 언어로 대화하면서 필요한 답변에만 번역·다른 언어 사용을 요청할 수 있어야 한다.

## 답변 언어 결정

현재 사용자가 번역 언어나 답변 언어를 명시하면 해당 답변에는 그 요청을 우선한다. 별도 요청이 없으면 현재 질문·입력의 언어로 답한다. 번역할 원문이나 인용문이 다른 언어여도 이를 질문을 작성한 언어 또는 명시한 번역 대상 언어와 혼동하지 않도록 안내한다.

영어 원문과 함께 “한국어로 번역해 줘”라고 요청하면 한국어 번역문을 답한다. 한국어 원문에 “영어로만 번역해 줘”라고 요청하면 영어 번역문을 답한다. 이후 새 질문에는 그 질문의 입력 언어를 적용한다. 이전 턴의 번역 지시·다른 언어 답변·압축 요약·개인 기억·웹과 파일 참고 자료는 현재 답변 언어를 바꾸는 지시로 삼지 않는다.

답변 본문·확인 질문·질문 카드 선택지에 같은 정책을 적용한다. 직접 입력한 이어 쓰기 요청에도 현재 입력의 명시적 요청과 주요 언어를 적용한다. **이어서 생성 버튼**은 잘린 답변의 언어를 유지하라는 지시를 이번 요청에 명시해 답변을 이어 간다. 이후 직접 입력한 새 질문에는 그 질문의 언어를 적용한다. 질문 카드 응답에 서버가 붙인 안내문은 사용자의 언어 의도로 간주하지 않는다.

한국어 답변에는 요청하지 않은 중국어 어휘가 섞이지 않도록 안내한다. 사용자가 요청한 다른 언어의 번역·인용, 코드와 고유명사의 원문은 보존한다. 한자 범위를 정규식으로 지우거나 생성 결과를 일괄 치환하지 않는다. 답변을 수정하기 위한 추가 모델 호출도 자동으로 수행하지 않는다.

## 문맥 구성과 사용량

언어 정책은 서버가 구성하는 답변 시스템 지침에 포함하며, 새 질문·재생성·이어 쓰기·질문 카드 응답과 문맥 압축 후의 답변에도 유지한다. 공급자 공통 입력 변환은 답변용 지침을 확인해 마지막 사용자 입력 복사본에 안내를 보강한다. 원문·개인 기억·첨부 파일·웹 참고 자료는 그대로 둔다.

입력 토큰 계산과 일반·도구 생성은 같은 변환을 거친다. 저장 원문·SSE·외부 검색 후보에 안내를 추가하지 않으며, 요약·검색 계획처럼 별도 시스템 지침을 쓰는 내부 호출에도 추가하지 않는다. 실제 답변에 사용한 안내는 기존 완료·중단 후 정산에 포함한다. 시스템 유지 요약의 별도 사용량 기록과 사용자 비차감 정책을 유지한다.

## 운영

언어 정책에 사용자별 저장값이나 생성별 언어 필드를 사용하지 않는다. DB head는 `0016_local_file_rag`이며 도메인·관측 테이블은 22개다. API와 독립 worker 코드를 함께 반영하며, 자동으로 코드를 다시 읽지 않는 독립 worker에는 앱의 정상 재시작이 필요하다.

## 검증과 한계

서버 검사는 답변 문맥의 언어 정책, 재생성·이어 쓰기·압축·질문 카드 경로, 입력 토큰 계산과 생성 입력 일치, 원문 보존을 다룬다. 실제 모델 평가는 [합성 언어 평가](../evaluations/answer-language-smoke.json)에 기록한다. 언어 지침은 혼용 가능성을 줄이지만 모델의 모든 출력을 보장하지 않는다.

평가는 기존 로컬 모델 서버가 실행 중일 때 `.venv/bin/python scripts/evaluate_answer_language.py`로 재현한다. 12개 표본에서 한국어·영어 입력, 양방향 번역, 번역 후 새 질문의 언어 복귀, 영어 답변 이어 쓰기, 일반·깊이 생각하기, 과거 중국어 혼용과 압축 요약, 코드·인용 보존과 입력 토큰 일치를 확인했다. 질문 도구를 허용한 요청에는 영어 확인 질문이 일반 본문으로 나왔으며, 실제 카드 생성의 언어 품질을 확인한 표본은 아니다. 적은 합성 표본으로 생성 설정의 인과 효과를 단정하지 않는다. 최종 검사와 실제 모델 평가 결과는 [개발 현황](../development-status.md)에 기록한다.
